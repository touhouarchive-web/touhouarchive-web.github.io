Source Register

Starting points for checking game history, character details, official books, and the images used across this site.

Sources are not interchangeable; cite the exact work where possible.

Primary and secondary starting points

  1. Touhou Koumakyou: New Classic — official website
    Official product information; selected character portraits and promotional imagery used in this archive are downloaded during the site build and credited in the visual source list below.
  2. Touhou Wiki — Touhou Project overview
    A useful secondary index to release order, official works, and further source pages. Verify important claims in the original game or publication when possible.
  3. Touhou Wiki — Reimu Hakurei
    Navigation to a character overview and its cited game/print appearances.
  4. Touhou Wiki — Hakurei Shrine
    Secondary location overview with listed game and print depictions.
  5. Touhou Wiki — Perfect Memento in Strict Sense
    Reference entry for the official compendium and its in-universe perspective.
  6. Neowing — Perfect Memento in Strict Sense listing
    Host/source for the bibliographic cover image used in print-work sections.
  7. AKIBA-HOBBY — Silent Sinner in Blue, Volume 1
    Host/source for the bibliographic cover image used on the official print-works page.

Image credits and limits

Displayed images are downloaded during the GitHub Pages build and served from this website’s own /assets/images/ path. A visitor’s browser therefore never hotlinks directly to Touhou Wiki or another image host. Image captions link to the actual source page for the displayed visual.

The site uses official promotional/game imagery where available, game-box and screenshot references from LaunchBox Games Database, publisher or retailer cover images for print works, and a small number of clearly labelled community illustrations for characters absent from the official promotional materials. Rights remain with the respective creators and publishers; credit links identify the displayed image’s source, and inclusion here does not imply that every image has a blanket reuse licence.

Research checklist

  • Verify a claim in the original game or official publication.
  • Record the game, route, stage, chapter, page, or track.
  • Quote translations carefully and note variants.
  • Separate in-universe claims from objective narration.
  • Use image captions and alt text.
